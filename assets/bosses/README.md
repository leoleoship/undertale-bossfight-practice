# Optional Boss Images

Put authorized boss images here if you want the game to draw images instead of the built-in tile sprites.

Expected filenames:

- `undyne.png`
- `asgore.png`
- `disbelief.png`
- `btt.png`
- `sans.png`
- `undying.png`
- `omega.png`
- `asriel.png`
- `mettaton.png`

The repository does not include copied Undertale screenshots or sprites. Use only images you have permission to publish.
